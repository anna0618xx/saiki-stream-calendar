# PCスクショ回収（Chrome/Edge 試験版）

佐伯配信手帳の「🖼 スクショ回収」から、ログイン済みの普通のYouTube視聴画面を順番に表示し、**開始10分付近**のフレームを撮影するローカル補助機能です。**画像、Cookie、パスワードはGitHubに送信されません。**

## 最初の導入（WindowsのChrome / Edge）

1. [リポジトリZIP](https://github.com/anna0618xx/saiki-stream-calendar/archive/refs/heads/main.zip) をダウンロードして展開します。
2. Chromeで `chrome://extensions/`（Edgeなら `edge://extensions/`）を開き、右上の「デベロッパーモード」をONにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、展開したフォルダ内の **`capture-extension`** フォルダを選択します。選ぶのは `manifest.json` ファイルではなく、フォルダです。
4. YouTubeでログイン状態を確認し、通常どおり公開アーカイブが再生できる状態にします。
5. [佐伯配信手帳](https://anna0618xx.github.io/saiki-stream-calendar/) をChromeで開き直し、統計欄の「🖼 スクショ回収」を押します。
6. 「8月20日〜9月30日（初回回収）」を選んで **「まず1件を試す」** を押してください。
7. YouTubeタブが自動で開閉します。画面が切り替わる間はマウス操作やタブ切り替えを控えてください。
8. 成功した配信の詳細に「🖼 PC候補あり」が出ます。「編集 → スクショ・代表画像 → この画像を採用」で確定できます。

うまくいけば「最大5件を回収」を繰り返して残りを処理できます。

## 毎週の運用

1. 週に1度PCを起動し、YouTubeにログインしたChromeでカレンダーを開きます。
2. 「🖼 スクショ回収 → 直近14日」を選択し、未登録の公開配信を確認します。
3. 最初は「まず1件を試す」、慣れたら「最大5件を回収」で少しずつ処理します。
4. 必要な画像を「編集」で採用し、Google Driveへの保存を実行します（**Driveは自動同期ではありません**）。

## 対象と保存

- 対象は**終了済み・公開・佐伯本人チャンネル**の配信。YouTubeの公開フィードから確認できる動画だけです。
- 貯金の「未計上」は画像の有無とは別です。**未計上でもスクショがある場合は対象外**、貯金済みでも画像がなければ対象です。
- メン限・非公開動画・他チャンネルの出演・スクショ/代表画像登録済み配信は自動対象に含めません。
- 撮影した画像はブラウザ側で **4:5 / WebP** に切り抜かれ、PCのIndexedDBへ**候補**として保存されます。未採用の候補を公開GitHubへアップロードしません。
- 「この画像を採用」した後、既存のバックアップ/Google Drive保存の対象になります。採用前の候補は **このPCだけ** で管理され、他の端末には自動で現れません。
- iPhoneホーム画面アプリではこの拡張機能は動きません。

## 権限について

現在のChrome APIの画面キャプチャ機能 `tabs.captureVisibleTab` は、拡張機能起動時以外にも継続して一括撮影する場合、`<all_urls>` という広いホスト権限が必要です。そのためインストール時に「すべてのサイトのデータを読み取り、変更する」旨の警告が表示される場合があります。

**試験版コードは佐伯配信手帳だけから起動を受け付け、撮影対象URLを通常の公開YouTube watchページの動画IDに限定しています。** その他のタブやサイトを走査しません。拡張機能のインストールは任意です。不要になったらChromeの拡張機能画面で無効化/削除してください。

## 制限と検証

- GitHub Actionsからの動画取得はYouTube側の `bot_check` により失敗したため、PC版では **yt-dlpやCookieの抽出を行わず、ユーザーの通常のブラウザ画面を撮影**します。
- 動画がロードできない、広告が表示中、視聴制限画面、再生が始まらない、求めた時間にシークできない、ブラウザが別タブに切り替わった等の場合は失敗します。**ブラウザでの実機検証はまだ**で、100%成功する保証はありません。
- 公開サイトの対象動画一覧が未読込なら、ページを再読込してください。ローカルの画像有無は利用中のPCだけで判定します。
- Chromeの拡張機能を更新した場合は `chrome://extensions/` で「更新」アイコンを押し、カレンダーも再読込してください。
- 最初の段階では連続5本までです。失敗ログの改善・自動候補選定は1本の動作確認後に調整します。

## 実装ファイル

- `manifest.json`: 拡張の権限と登録先
- `bridge.js`: 佐伯配信手帳との通信（指定originのみ）
- `worker.js`: 1動画ずつタブを開く → 10分地点へ移動 → 可視画面を撮影 → 元のタブへ結果を送信
- `../index.html`: 未登録抽出・実行ボタン・ローカル切り抜き候補の保存と採用UI

元のGitHub Actionsは変更しません。失敗したサーバー側の自動取得と独立して使用できます。
